Measurement system · Gage R&R

Know whether you can trust the measurement

An R&R study shows how much of the variation comes from the measuring equipment and from the operators. The app guides data entry, computes the result live and explains how to read it.

MSA type 2AIAG MSAC++ / WebAssembly

The problem

Before: a poorly understood method

Before

  1. A method little known outside quality
  2. Results that are hard to interpret
  3. A tool that was hard to read

Now

  1. The verdict updates during data entry
  2. Data sheets with a random order, ready to print
  3. A built-in guide: what the study is for, how to read the result
  4. A clean report to attach to the file
The application

From data sheet to report

The study

Average and range method, according to the AIAG MSA manual.

  • 10 parts, 3 operators, 3 trials by default
  • %R&R against tolerance and total variation
  • Number of distinct categories (ndc)
  • Decision: capable, conditionally acceptable, not capable
  • Reference data set to check the calculation

Around the study

What makes the method usable by everyone.

  • Data sheets with a randomly drawn measuring order
  • Printable report with the variance components
  • Guide: purpose, execution, reading the results
  • Opens directly from an equipment record
  • Light or dark theme
